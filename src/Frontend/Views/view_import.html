Before you import

For the best results, your SketchUp model and your SolidCutlist library should be aligned before you proceed:

  • Material names in SketchUp should match those in your SolidCutlist library
  • Component dimensions should match your available profiles — SolidCutlist will pick the closest one automatically
  • Component Definition names will become Part Names — check they are meaningful before exporting
  • Group Instance names will become Groups in SolidCutlist — add any missing groups to your library first

The import is always additive — nothing in your existing parts list will be overwritten.
